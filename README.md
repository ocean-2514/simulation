# Simulation

一个以算法学习和编程实践为目标的 C++ / OpenGL 小型引擎项目。项目包含轻量的窗口、输入和几何绘制框架，以及正在持续完善的二维刚体物理模块。开发重点是实现物理算法本身，并通过交互场景观察碰撞、约束与数值误差如何影响模拟。

本项目仍处于开发阶段，主要用于学习和实验，不是 Bullet 等成熟物理引擎的替代品。当前物理模块专注于 2D 刚体；仓库中的 3D 几何代码不代表已经支持 3D 物理。

## 项目概况

| 项目 | 说明 |
|---|---|
| 语言与标准 | C++17 |
| 图形接口 | OpenGL 3.3 Core Profile |
| 窗口与输入 | GLFW |
| OpenGL 函数加载 | GLAD |
| 数学库 | GLM |
| 构建系统 | CMake；当前仓库配置面向 Windows + MinGW |
| 主要实现方向 | 二维刚体、碰撞检测、接触约束与关节求解 |

## 当前功能

- **图形与窗口：** OpenGL 3.3 Core 窗口、GLSL 着色器、简单的 2D 网格绘制和键盘输入。
- **刚体状态：** 静态、运动学和动态三类刚体；动态物体支持重力、外力、扭矩、线速度和角速度积分。
- **碰撞形状：** 圆形和凸多边形。圆形碰撞对提供一个接触点；凸多边形面接触可输出最多两个点的接触流形。
- **宽相与窄相：** 使用 BVH 动态 AABB 树查找候选对，再由圆-圆、圆-凸多边形和凸多边形 SAT/裁剪算法进行窄相检测。
- **接触求解：** 顺序冲量速度求解、恢复与库仑摩擦、局部锚点位置修正，以及按接触特征匹配的跨子步冲量 warm start。
- **碰撞过滤：** 刚体碰撞类别和双向掩码决定候选对象是否进入窄相和接触求解。
- **约束与力：** 距离、固定和铰链约束；独立的力生成器接口及弹簧阻尼力生成器。
- **演示场景：** 封闭边界、球堆、凸多边形、运动学控制物体、固定物体、铰链物体和弹簧连接物体。

更详细的模块和算法说明见[架构概览](docs/architecture.md)与[二维物理模块](docs/physics.md)。

## 运行演示

当前演示使用 W/A/S/D 控制运动学三角形，按 Esc 退出。场景中的球堆可用于观察密集接触与摩擦；移动三角形可以与动态物体交互；固定物体、铰链物体和弹簧展示了约束与力生成器的基本用法。

详细依赖和构建步骤见[构建与运行](docs/build.md)。在 Windows 的 MinGW 环境中，基本命令如下：

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
.\build\bin\simulation.exe
```

## 设计概览

物理碰撞数据与绘制网格分别存储：`Collider` 保存圆半径或多边形顶点/法线，`Shape` 管理用于绘制的 OpenGL 缓冲区。演示通过 `ShapeProxy` 将绘制对象与 `PhysicsWorld` 中的 `BodyId` 关联起来。这样碰撞检测不需要从 GPU 网格缓冲区读取几何数据。

`PhysicsWorld` 负责刚体集合、BVH 代理、力生成器、用户约束与每个子步创建的临时接触约束。接触约束只在当前子步存在；跨子步的冲量另存于 `ContactCache`，用稳定的刚体对和接触特征匹配。

程序入口创建 `Engine` 和具体 `Application`，由引擎初始化 OpenGL 上下文后再构造场景几何。每帧引擎推进物理世界，应用随后处理输入并绘制场景。这样演示代码可以通过 `ShapeProxy` 读取物理变换，而物理求解本身不依赖 OpenGL 顶点缓冲区。

## 适合展示的技术内容

- 基于 AABB 的动态 BVH：fat bounds 减少频繁重插入，插入时使用表面积代价选择兄弟节点，并通过树旋转进行高度平衡。
- 凸多边形 SAT：同时查询两个多边形的边法线，选择参考面和入射边，再通过侧面裁剪构建接触流形。
- Sequential Impulse：累积法向冲量并投影到非负范围，切向冲量限制在摩擦区间内，支持多轮迭代与 warm start。
- 约束统一迭代接口：接触、距离、固定和铰链约束通过相同的 `Prepare / WarmStart / SolveVelocity / SolvePosition` 阶段参与求解。
- 显式区分物理碰撞体和渲染几何，便于独立扩展算法和演示层。

## 当前范围与限制

物理模块目前只模拟二维圆形和凸多边形刚体。虽然仓库中有少量 3D 几何类，但尚未实现 3D 刚体物理、连续碰撞检测（CCD）、凹多边形分解、布料、软体或流体模拟。求解器使用有限轮数的逐点顺序迭代，没有双点法向块求解；密集堆叠和极端时间步仍可能出现数值误差。

当前没有独立的自动化物理测试套件；演示场景主要用于交互观察和手动验证。
